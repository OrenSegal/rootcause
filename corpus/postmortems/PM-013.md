title: Lint gate failed on a newly added test script
date: '2026-01-09'
services: [ci]
---
The CI lint job runs shellcheck at warning level on every shell script. A new test script used a function argument pattern that shellcheck reports as a warning, so the job failed.

The same commit also edited the workflow file, which looked like the cause. The failing step and the file it names point at the new script.

Fix: rewrote the function call; no change to the workflow.
