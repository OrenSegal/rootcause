---
id: PM-011
title: Tests that pass locally and fail only in CI
date: '2025-12-04'
services: [ci]
---
A batch of install tests passed on every laptop and failed on the CI runners. The tool under test treated either CI or GITHUB_ACTIONS being set as running in CI, but the tests only unset CI to simulate a local run. On the runners GITHUB_ACTIONS was still set, so the tool took its CI branch.

The commit that introduced the CI detection also added the tests. A later refactor that moved the detection into a helper was blamed first because it was the newest commit.

Fix: tests unset every CI marker. Lesson: when only CI fails, look for environment differences and find the commit that introduced the behavior, not the latest one.
