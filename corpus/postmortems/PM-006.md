---
id: PM-006
title: Ranking model rollout raised search latency
date: '2025-09-03'
services: [search]
---
A new ranking model raised search p99 from 120ms to 450ms. No errors, no restarts, memory flat.

Root cause: the model's feature lookups were not batched. Rolled back the model; latency recovered immediately.

Distinguishing it from capacity problems: latency moved at the exact deploy minute and stayed flat afterwards, and resource usage did not trend.
