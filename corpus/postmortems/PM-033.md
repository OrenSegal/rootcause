---
id: PM-033
title: A chatops bot followed instructions found in log text
date: '2026-03-12'
services: [security, chatops]
---
Our chatops bot summarized recent error logs and could open rollback requests. A log line contained text a user had typed into a search box, phrased as an instruction to roll back a release. The bot opened the rollback request. A human declined it.

Root cause: the bot treated data as instructions. Logs, tickets and user input are data even when they are phrased as commands.

Fix: tool calls that change production are proposed only from the bot's own analysis, and any rollback must cite telemetry that implicates the release.
