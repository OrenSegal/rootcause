title: Consistency test failed when a plugin was added
date: '2025-12-15'
services: [ci]
---
A test checks that the README table lists exactly the plugins in the marketplace manifest. A commit added a plugin to the manifest without adding its row to the README, and the test failed on every platform.

Not flaky and not environmental: the assertion message lists the README rows, and the missing name is the plugin added in that commit.

Fix: added the row; the contributing guide now says to update both.
