---
id: PM-023
title: Key rotation that left the old key unaccepted
date: '2025-06-30'
services: [auth]
---
A signing key rotation removed the previous key from the accepted set too early, so tokens signed minutes before the rotation were rejected. All users were affected for 10 minutes, spread evenly across instances.

Fix: keep the previous key accepted for one token lifetime. Distinguishing feature: rejections across every issuer, not one node.
