---
id: PM-017
title: Runtime flag flip changed pricing with no deploy
date: '2026-01-27'
services: [pricing, checkout]
---
A pricing flag that allows discounts to stack was switched on at 100% from the flag service. No deploy, so the deploy list showed nothing for pricing. Checkout started rejecting orders whose cart total no longer matched the quote.

How we found it: the pricing service logs every runtime flag change with the actor. That log line came 30 seconds before the first mismatch.

Fix: flag turned off; stacking now has a ramp and a guard on maximum discount. Lesson: when no deploy explains a change, check runtime flag changes.
