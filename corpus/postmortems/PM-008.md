---
id: PM-008
title: Reservation code path shipped without a feature flag
date: '2025-08-27'
services: [inventory]
---
An inventory release turned on a new reservation path for all traffic at once. One minute later reservations started failing with a null reference in the new code, and inventory errors went to 15%.

Impact: 20 minutes of failed add-to-cart.

Root cause: a code defect in the release, exposed to 100% of traffic because the new path had no flag.

Fix: rolled back the release; the path was re-released behind a flag with a 1% start.
